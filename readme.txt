Sistema de Gestão de Entradas e Saídas
Objetivo:

Desenvolver um sistema financeiro simples utilizando Python e Streamlit para registrar entradas e saídas financeiras, calcular o saldo automaticamente e exibir um histórico das movimentações realizadas.

Tecnologias Utilizadas:
Python
Streamlit

Funcionalidades:
Cadastro de entradas
Cadastro de saídas
Cálculo automático do saldo
Histórico de movimentações
Interface gráfica utilizando Streamlit

Como Executar

Instale as dependências:

pip install -r requirements.txt

Execute o sistema:

python -m streamlit run app.py

Estrutura do Projeto:

app.py
Interface gráfica do sistema

caixa.py
Funções responsáveis pelas operações financeiras

requirements.txt
Bibliotecas necessárias

README.md
Documentação do projeto

Dificuldades Encontradas:
Organização da lógica em módulos separados.
Controle das movimentações durante a execução.
Integração da interface Streamlit com as funções Python.
